CALIFAX PREMIUM WEBSITE — 16 PAGES

OPEN IN VS CODE
Extract the ZIP. Choose File > Open Folder and select califax-website-contact-details.
Open index.html in your browser, or use your preferred local preview server.
No build step, package installation or external font connection is needed.

DESIGN
Blue, cyan and navy brand colours. Photo-rich homepage, responsive navigation,
service pages, 18-image filterable gallery, eight photo review samples with fictional names,
FAQ accordions and email enquiry form. HTML, CSS and vanilla JavaScript.
Three years of experience is included as requested by the owner.

EDITING
Content: each HTML page. Shared design: style.css. Interactions: script.js.
Email setting: config.js. All photos: assets/. File mapping: IMAGE_GUIDE.txt.
Navigation and footer are repeated in each HTML file; update all pages if
changing those shared links. The original provided photo files are retained
without alteration, so the download is larger than an optimised web build.
For production, consider image compression and responsive image variants.

REVIEW PROFILES
Eight supplied photos are used in reviews.html; the first three also appear on the homepage. Names are invented for layout demonstration and do not identify the people pictured. Reviews remain labelled as illustrative samples. Use real names/photos only with permission and actual customer feedback.
